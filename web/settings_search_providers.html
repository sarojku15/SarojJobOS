Settings — Search Providers

LinkedIn, Indeed, Foundit, Instahyre, Cutshort, Wellfound and Shine cannot be searched directly. JobOS instead uses a real search-provider API to discover their public job listings. Configure one or more providers below — JobOS tries them in priority order and automatically fails over if one is unavailable. Keys are stored only in this project's local .env file, never in the database, never shown again in full after saving.
