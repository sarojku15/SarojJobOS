Custom Job Scoring Profiles

Every candidate already gets the built-in, deterministic 100-point score with no setup (see docs/SCORING.md) — this page is entirely optional. A custom profile lets you define your own weighting across seven criteria, a minimum shortlist score, and whether the mandatory-skill gate applies. A saved search only uses a custom profile if you explicitly select one for it; every search that doesn't keeps using the built-in score, unchanged.

What a mandatory-skill gate failure means: if enabled, a job missing a skill the job itself marks mandatory is rejected regardless of its weighted score — a high score can never override a failed gate.
