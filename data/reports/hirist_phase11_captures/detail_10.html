Junior DevOps Engineer - Docker/Terraform

Hostment
1 - 3 Years
Mohali

Posted on: 15/09/2026

Job Description

About the Role :

We are looking for a motivated and detail-oriented Junior DevOps Engineer with 1 - 3 years of hands-on experience in cloud infrastructure, CI/CD pipelines, and deployment automation. The ideal candidate should have practical knowledge of AWS services, Linux environments, and DevOps tools to support application deployment and infrastructure management.

Key Responsibilities :

- Manage and monitor AWS cloud infrastructure and services.

- Build, maintain, and optimize CI/CD pipelines.

- Deploy and manage applications in development, staging, and production environments.

- Work with Docker and containerized applications.

- Monitor system performance, uptime, and troubleshoot deployment issues.

- Maintain security best practices and backup strategies.

- Support infrastructure scaling and server maintenance.

Requirements :

- Basic to intermediate knowledge of AWS services (EC2, S3, IAM, RDS, CloudWatch, VPC, Amplify, Lightsail).

- Experience with CI/CD tools such as Jenkins, GitHub Actions, or GitLab CI/CD.

- Familiarity with Docker and containerization.

- Understanding of Infrastructure as Code tools like Terraform or Cloud Formation.

- Experience with version control systems like Git.

- Basic scripting knowledge in Shell, Python, or Bash.

- Understanding of networking and security concepts.

Benefits :

- Inter-tech work

- Skill upgradation trainings

- Soft skills trainings

- Rewards and recognitions

- Weekly de-stressing activities

Location : Mohali, Punjab
