# Code of Conduct

## Our Pledge

We as contributors and maintainers pledge to make participation in
this project a harassment-free experience for everyone, regardless of
age, body size, visible or invisible disability, ethnicity, sex
characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance,
race, religion, or sexual identity and orientation.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Using welcoming and inclusive language
- Being respectful of differing viewpoints and experiences
- Gracefully accepting constructive criticism
- Focusing on what is best for the project and its users

Examples of unacceptable behavior:

- Harassment, insulting/derogatory comments, or personal attacks
- Publishing others' private information (including real candidate
  data, resumes, or API keys found in this project) without explicit
  permission
- Other conduct which could reasonably be considered inappropriate in
  a professional setting

## Scope

This Code of Conduct applies within project spaces (issues, pull
requests, discussions) and in public spaces when an individual is
representing the project.

## Enforcement

Instances of abusive, harassing, or otherwise unacceptable behavior
may be reported by opening a private report through GitHub (see
[SECURITY.md](SECURITY.md) for how this repository currently handles
private reports) or, where none is available, by contacting the
repository maintainer directly through their GitHub profile. All
complaints will be reviewed and investigated.

This Code of Conduct is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
